<task name="Replace sendEmail with Resend integration">
Update the `sendEmail` function in `src/lib/services/email-service.ts`:

Current state: Lines 310-352 just log to console.

Replace with:
```typescript
async function sendEmail(
  email: EmailPayload,
  type: string,
  orderId?: number
): Promise<EmailNotificationLog | null> {
  const log: EmailNotificationLog = {
    id: `email_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`,
    to: email.to,
    subject: email.subject,
    type,
    orderId,
    sentAt: new Date(),
    success: false,
  };

  try {
    const html = email.html || (email.templateId ? generateTemplate(email.templateId, email.data || {}) : '');

    // Fire-and-forget: don't block order processing
    const resendApiKey = process.env.RESEND_API_KEY;
    if (!resendApiKey) {
      console.warn('⚠️ RESEND_API_KEY not configured, skipping email send');
      log.success = true; // Don't fail the order
      return log;
    }

    const { Resend } = await import('resend');
    const resend = new Resend(resendApiKey);
    const fromEmail = process.env.RESEND_FROM_EMAIL || 'LogoGenius <noreply@logogenius.com>';

    await resend.emails.send({
      from: fromEmail,
      to: email.to,
      subject: email.subject,
      html,
    });

    console.log(`✅ Email sent: ${type} to ${email.to}`);
    log.success = true;
    return log;
  } catch (error) {
    // Don't throw — email failure should not block order processing
    log.success = false;
    log.error = error instanceof Error ? error.message : 'Unknown error';
    console.error(`❌ Failed to send email: ${type}`, error);
    return log;
  }
}
```

Key changes:
- Import Resend dynamically
- Send via `resend.emails.send()`
- Graceful fallback if RESEND_API_KEY not set (warns but doesn't fail)
- Catches errors without throwing (fire-and-forget)
- Uses RESEND_FROM_EMAIL env var for sender

<verify>sendEmail function uses Resend API, catches errors without throwing</verify>
