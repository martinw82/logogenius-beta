<action>
1. Start the Next.js dev server if not running: `npm run dev`
2. Send POST request to `/api/test/pdf-generation` with body:
   ```json
   {
     "businessName": "Test Brand Co",
     "tagline": "Testing Puppeteer PDF",
     "archetype": "The Hero",
     "primaryColor": "#2563EB",
     "secondaryColor": "#10B981",
     "accentColor": "#F59E0B",
     "fontHeadings": "Playfair Display",
     "fontBody": "Inter",
     "generatePdf": true
   }
   ```
3. Verify response: `success: true`, `pdfBase64` is non-null, `pdfSizeKb` > 10
4. Save the PDF from base64 to `test-output-phase4.pdf` for visual review
5. Check `totalMs` — log generation time
</action>
<acceptance_criteria>
- POST /api/test/pdf-generation returns `success: true`
- Response contains `pdfBase64` (non-null, non-empty)
- `pdfSizeKb` is greater than 10
- `totalMs` is logged
- PDF file saved to `test-output-phase4.pdf`
</acceptance_criteria>
</task>
