<task name="Create webhook API route">
Create `src/app/api/stripe/webhook/route.ts`:

- POST handler (no auth — Stripe signs requests)
- Read raw body as text: `const body = await request.text()`
- Get signature from header: `const sig = request.headers.get('stripe-signature')`
- Verify signature: `stripe.webhooks.constructEvent(body, sig, STRIPE_WEBHOOK_SECRET)`
- Handle `checkout.session.completed` event:
  1. Extract metadata: { tier, customerEmail } from session
  2. Check idempotency: query Order by stripeSessionId — if exists, return 200
  3. Create Order with: tier, customerEmail, stripeSessionId, paymentStatus="paid", amount=session.amount_total
  4. Log: `console.log('Order created:', order.id, 'for session:', session.id)`
- Return 200 for ALL events (even unhandled — prevents Stripe retries)

Note: App Router provides raw body by default. No special config needed (unlike Pages Router). Just use `await request.text()`.

<verify>Endpoint exists at /api/stripe/webhook, accepts POST, verifies signatures</verify>
<done>Webhook endpoint processes checkout.session.completed events and creates orders</done>
</task>

<task name="Implement idempotent order creation">
In the webhook handler's `checkout.session.completed` branch:

```typescript
// Idempotency check — don't create duplicate orders
const existingOrder = await prisma.order.findFirst({
  where: { stripeSessionId: session.id }
});
if (existingOrder) {
  console.log(`Order already exists for session ${session.id}, skipping`);
  return new Response(null, { status: 200 });
}

// Create order with payment data
const order = await prisma.order.create({
  data: {
    tier: metadata.tier,
    customerEmail: metadata.customerEmail,
    stripeSessionId: session.id,
    paymentStatus: 'paid',
    amount: session.amount_total,
    status: 'pending',
  }
});
```

<verify>Duplicate webhook events don't create duplicate orders (test by sending same event twice)</verify>
<done>Idempotency check prevents duplicate orders from webhook retries</done>
</task>

<task name="Handle webhook error cases">
- Invalid signature → return 400 with error message
- Missing metadata → log warning, return 200 (don't retry)
- Database error → log error, return 500 (Stripe will retry)
- Unknown event type → log, return 200
