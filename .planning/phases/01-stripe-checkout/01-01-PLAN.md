<task name="Create checkout session API route">
Create `src/app/api/stripe/checkout/route.ts`:

- POST handler that accepts `{ tier, customerEmail }`
- Validates tier is one of: basic, pro, premium (internal IDs — keep existing codebase convention)
- Maps tier to Stripe Price ID from env vars:
  - `basic` → `STRIPE_PRICE_STARTER` (Starter $29)
  - `pro` → `STRIPE_PRICE_PRO` (Professional $49)
  - `premium` → `STRIPE_PRICE_ENTERPRISE` (Enterprise $99)
- Creates Stripe Checkout Session with:
  - line_items: [{ price: priceId, quantity: 1 }]
  - mode: "payment" (one-time, not subscription)
  - metadata: { tier, customerEmail }
  - success_url: `${NEXT_PUBLIC_BASE_URL}/order/success?session_id={CHECKOUT_SESSION_ID}`
  - cancel_url: `${NEXT_PUBLIC_BASE_URL}/tiers`
- Returns { sessionId, url } for frontend redirect

Use dynamic import pattern: `const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!)`
<verify>TypeScript compiles, POST returns valid Stripe session URL</verify>
<done>Stripe checkout API route created and returns valid session URLs</done>
</task>
