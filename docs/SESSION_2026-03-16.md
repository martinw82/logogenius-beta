## 🏗️ Architecture Overview

### Font Data Flow
```
Admin/Customer Form → OrderDetail Records → Order Processor → PDF Generator
     ↓                        ↓                       ↓              ↓
Typography Fields → fontHeadings, fontBody, etc. → Font Objects → Embedded Fonts
```

### Font Storage
```
Upload → Validation → File Storage → Database Reference → PDF Registration
TTF/OTF → Size/Type Check → /uploads/fonts/ → OrderDetail → doc.registerFont()
```

### Typography Features
- **System Fonts**: 26 professional fonts pre-installed
- **Custom Uploads**: TTF/OTF support with 5MB limit
- **Font Previews**: Canvas-based visualization
- **PDF Integration**: Embedded fonts in brand guides
- **Logo Override**: Selected fonts can override logo generation
