## 🏗️ Technical Decisions Made

### 1. Client-Side Rendering Strategy
**Decision:** Use HTML5 Canvas in browser instead of server-side Puppeteer

**Why:**
- Works on Vercel (no native dependencies)
- $0 cost (no API calls)
- Fast rendering (~2s for mockups, ~5s for social)
- Full control over design

**Trade-off:** Requires browser to complete generation (admin must keep page open)

---

### 2. Upload Pattern
**Decision:** Client renders → converts to base64 → uploads to API

**Flow:**
```
Canvas → toDataURL() → base64 string → POST /upload-mockups → Server saves to DB
```

**Why:** Server can't access Canvas, so client must render and upload

---

### 3. Mockup Template Design
**Decision:** Canvas-based templates with brand color integration

**Each template includes:**
- Background with brand colors
- Logo overlay at specific position
- Business name and tagline
- Platform-appropriate design elements
