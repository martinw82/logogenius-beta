## 🐛 Bugs Fixed

### Bug 1: Mockups Only Generated for Variant 1
**Problem:** The mockup generator was hardcoded to only generate mockups for `variantNum: 1`, leaving variants 2-4 with placeholder images.

**Root Cause:** 
- `useClientMockupGenerator.ts` had `variantNum: 1` hardcoded in the upload call
- The hook only accepted a single logo URL, not an array of all variants

**Fix:**
- Updated `useClientMockupGenerator.ts` interface to accept `LogoVariant[]` array
- Modified `generateAndUploadMockups()` to loop through all 4 variants
- Each variant now gets its own 3 mockups (businesscard, letterhead, tshirt)
- Uploads each variant separately with correct `variantNum`
- Progress indicator updated to show "Generating {template} for Variant {N}..."

**Files Modified:**
- `src/hooks/useClientMockupGenerator.ts`
- `src/app/admin/orders/[id]/page.tsx`

---

### Bug 2: Social Media Assets Not Displaying
**Problem:** Social media assets were being generated but not displaying in the admin UI - all showed "Not generated yet"

**Root Cause:**
- **Hook** saved field names with hyphens: `social_instagram-post`
- **Admin page** looked for field names with underscores: `social_instagram_post`

**Fix:**
- Added `PLATFORM_KEY_MAP` in `useClientSocialGenerator.ts` to map internal hyphenated names to underscore names for storage
- Social assets now stored with correct keys that match the UI expectations

**Files Modified:**
- `src/hooks/useClientSocialGenerator.ts`

---

### Bug 3: Admin API Only Returned Mockups for Variant 1
**Problem:** The admin API was filtering mockups to only include them for `variantNum === 1`

**Root Cause:**
- `src/app/api/admin/orders/[id]/route.ts` had hardcoded check `if (variant.variantNum === 1)`

**Fix:**
- Removed the variant number check
- Now returns `mockupPaths` directly from the database for all variants

**Files Modified:**
- `src/app/api/admin/orders/[id]/route.ts`

---

### Bug 4: Tier Check Too Strict
**Problem:** Social media section wasn't showing for some tier formats

**Fix:**
- Updated tier check in admin page to be more flexible:
  - Before: `order.tier === 'premium'`
  - After: includes checks for '3', 'tier 3', 'tier3', case-insensitive

**Files Modified:**
- `src/app/admin/orders/[id]/page.tsx`
